# Codex Style Annotations

[English](README.md) | [简体中文](README.zh-CN.md)

`paseo-plugins` 收录我自己维护的公开 Paseo 插件。Codex Style Annotations
目前位于仓库根目录，插件 ID 仍为 `quote-notes`。

把你指的那段原文交给 Paseo Agent。在聊天、文件、Markdown 预览、Diff 或终端中选中文字，将其添加到对话，再按需补充评论。

![选中的原文、可选评论和紧凑的草稿注释。界面示意图使用示例内容。](assets/preview.png)

## 把原文添加到对话

1. 选中希望 Agent 使用的文字。
2. 点击「添加到对话」。注释立即出现在草稿中。
3. 按需补充评论，再使用 Paseo 的正常消息控件发送草稿。

工作区选区会显示「添加到 {对话名称} 对话」，默认使用同一工作区最近聚焦的聊天。点击工具栏的箭头可以切换接收者，接收对话的输入框不必处于打开状态。

添加注释不会发送消息。你可以先收集多段选文，再一起发送。

## 使用工作区里的文字

![文件、Diff 和终端选区，以及显示接收对话名称的工具栏。界面示意图使用示例内容。](assets/workspace-sources.png)

| 来源 | 使用场景 | 注释保留的内容 |
| --- | --- | --- |
| 聊天 | 对 Agent 回复中的某一段提出意见。 | 渲染后的选文和宿主提供的 Markdown。 |
| 文件编辑器 | 询问某个函数，或要求修改选中的代码。 | 一段连续文字、文件路径、行号和文档指纹。 |
| Markdown 预览 | 针对预览中的段落提出改写要求。 | 渲染后的文字和文件路径，不推算源码行号。 |
| Diff | 解释或修改某个文件单侧的变更。 | 左右布局或统一布局中，单个文件、单侧的连续选区。 |
| 终端 | 附上需要处理的报错或日志。 | 选文、终端会话、缓冲区类型和缓冲区坐标。 |

采集不会读取剪贴板，也不会向终端发送输入。目前不支持网页内容注释。

跳回来源需要原始内容仍可定位。文件精确高亮要求内容一致，包括未保存的修改。Diff 采集拒绝混合文件、混合侧、区块标题和不连续范围；重开时不验证原行位置，工作区比较引用也可能变化。后续终端输出、缩放、关闭或重载可能使精确定位失效。过长的定位元数据可能被拒绝。

原文位置失效后，已保存的文字仍可读取，草稿注释仍可编辑或移除。

## 管理草稿和已发送注释

![草稿和已发送注释的界面示意图，使用示例内容，文案统一为英文。](assets/draft-and-sent.png)

介绍示意图使用英文文案方便说明；当前运行时的部分弹窗仍为中文。下面是隔离验证中使用中文示例文字截取的实际草稿摘要。

![实际草稿摘要界面，使用中文示例文字，以三倍设备像素比截取。](assets/interface/draft-summary.png)

草稿和已发送注释都会收成数量胶囊。悬停或聚焦草稿胶囊可查看条目，点击可固定展开。通过条目的编辑卡片修改评论或删除注释；在原文仍可定位时，点击摘要条目可跳回来源。

| 操作 | 键盘行为 |
| --- | --- |
| 新建评论 | Enter、Esc 或离开输入框保存当前文字。Shift+Enter 换行。输入法组词不会确认评论。 |
| 编辑已有评论 | Enter 换行。macOS 使用 Cmd+Enter 保存，其他平台使用 Ctrl+Enter。 |
| 放弃尚未提交的修改 | 点击「取消」、按 Esc 或点击外部，关闭编辑卡片并放弃这些修改。 |
| 阅读已发送注释 | 点击胶囊，或按 Enter、Space，展开完整文字。Esc 关闭预览并恢复焦点。 |

已发送注释为只读。由于 Paseo 发送后不再单独保存评论元数据，预览中的完整文字也包含评论。每条已发送注释都可以复制。

通过校验的待确认消息会在确认前后保留同一个胶囊。不支持的消息，以及原生适配器尚未就绪时的消息，会保留原生附件样式。

保存或删除结果未确认时，请先处理错误，再重载或停用插件。重试文字只保存在内存中；关闭卡片不会撤销已经尝试提交的操作。

## 选择来源和语言

打开「设置 > 插件 > Codex Style Annotations > 注释类型」。聊天、文件、Diff、Markdown 和终端采集各有独立开关，默认全部开启。设置属于对应主机上的插件安装。关闭某个类型只影响新注释，已有注释和聊天侧边提问仍可使用。

插件启动时读取设置，每次添加前再次检查。读取失败和保存冲突会显示错误，不会重置已保存的值。

设置、选区工具栏和侧边提问编辑框跟随 Paseo 的中英文设置，其他语言回退到英文。部分注释弹窗仍使用中文，包括评论编辑卡片和注释摘要。

## 针对聊天选文侧边提问

对聊天选区使用「在侧边聊天中提问」，再输入问题。子 Agent 沿用主对话的供应商、模型、模式和思考档位，收到选文、可获取的来源消息，以及最多八轮近期主对话。可在侧栏继续提问，也可打开为普通聊天标签。

目前不支持针对文件、Markdown、Diff 和终端选区发起侧边提问。

## 安装

需要 Paseo 0.11.4 或更高版本，并支持原生插件设置。先在「设置 > 插件」中启用插件。若已安装原版 `quote` 插件，请先停用。

```bash
paseo plugin disable quote
paseo plugin add xzthemeofsss/quote-notes
```

没有安装 `quote` 时，跳过停用命令。运行时 ID 保持为 `quote-notes`；原版插件保存的注释仍可读取，编辑时保留其身份信息。

如需直接安装源码发布版本，使用：

```bash
paseo plugin add git:xzthemeofsss/paseo-plugins --ref v0.2.1
```

市场使用已经审查的版本；上面的直接安装命令选择 `v0.2.1` 源码发布版本。

## 数据和兼容性

插件以受信任代码运行，读取选区、来源上下文、同工作区的 Agent 与草稿、已发送附件、注释设置，以及侧边提问需要的近期对话。注释保存在 Paseo 原生草稿中。发送草稿或侧边提问时，内容通过配置的模型供应商发送。主动复制条目时会写入剪贴板。

适配器会检查应用私有接口，并从同源读取 Paseo 自身的 JavaScript 包。Paseo 升级后可能需要适配更新。插件不添加外部后端，也不在运行时安装软件。停用插件会恢复原生附件卡片，并保留已保存的注释。

聊天界面已在 macOS Paseo 0.11.4 上检查。针对已安装 0.12.0-beta.3 渲染器的隔离浏览器验证覆盖了工作区采集、明暗工具栏、窄窗口、语言切换和待确认消息胶囊。这些验证不代表所有运行中的客户端均已确认。完整浏览器客户端和移动端尚未独立验证，移动端使用系统选区菜单。

## 开发

```bash
npm ci --ignore-scripts
npm run typecheck
npm test
```

保留的测试读取本机安装的 Paseo 原生模块，可通过 `PASEO_BUNDLE` 指定其他应用包。测试不会安装插件或向 Agent 发送消息。运行时模块由 Paseo 提供，安装插件无需构建或安装依赖。

介绍图片保留可编辑的 SVG 源文件及导出的 PNG，渲染命令和实际界面图片的来源见[图片说明](assets/README.md)。
