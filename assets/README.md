# Listing assets

The three illustrated gallery images are 1600 by 900 pixels. `icon.png` is 512 by 512 pixels. Each has an editable SVG beside its PNG export.

| File | Purpose |
| --- | --- |
| `preview` | Selected text, its optional comment, the asymmetric marker, and the draft capsule. |
| `workspace-sources` | File, Diff, and terminal examples with the receiving-chat toolbar. |
| `draft-and-sent` | Illustrations of draft editing, sent text, and source-type settings. |
| `icon` | Original highlighted-text and annotation-marker design. |
| `interface/draft-summary.png` | Actual current draft-summary interface with Chinese sample text. |

The three designed images are labeled illustrations with sample content. They use English labels for explanation and do not represent screenshots or prove complete runtime localization. Some current annotation popovers still use Chinese labels.

The fourth gallery item is a raw screenshot of the actual draft-summary component from this source revision in an isolated browser fixture. It was captured at a device scale factor of 3, with Chinese sample text and no translated or overlaid controls. The fixture confirmed that the component retains its one-pixel border and has no box shadow. The screenshot does not certify every running Paseo client.

## Export the PNGs

Use Node.js with an existing [Sharp](https://sharp.pixelplumbing.com/) installation:

```bash
node scripts/export-assets.mjs /absolute/path/to/project-with-sharp/package.json
```

The script resolves Sharp from that project and exports the four SVGs into their adjacent PNGs. It does not install dependencies or change plugin behavior. If Sharp is already available in this repository's module resolution path, omit the argument. The actual screenshot is an input artifact and is not regenerated by this command.
